  unsafe credential files, exec token/exit-code/argument forwarding, headers.
- `scripts/build.sh` (six targets, archives, `checksums.txt`, `manifest.json`),
  `Makefile`, CI workflow (Linux check + Windows vet/tests), tag-triggered
  prerelease workflow.

## Deliberate deviations from the spec for the alpha

- Unsigned binaries, no installers, no cosign/SBOM yet.
- Windows credential DACL verification is a placeholder (relies on `%APPDATA%`
  default ACLs). Tracked in TODO as the first Windows follow-up.
- Stdin/file inputs are buffered in memory (bounded 50 MiB) rather than spooled
  to a protected temp file. Same content-length guarantee, no temp data risk.
- Only Linux amd64 was runtime-tested today; the other five targets are
  cross-builds.

## Live smoke evidence (linux-amd64 archive binary, production)

Existing Node profile file loaded without login. `whoami --json` returned
account/entitlements/quota. Disposable 200,000-byte random file: `put` →
ready/200000/application-octet-stream; `get -o` SHA-256 matched the source;
`share --expires 5m --json` returned an `/s/` reader link; `revoke --yes`,
`list --limit 3` (pipe: 3 IDs + cursor hint on stderr), `delete --yes`, and a
follow-up `info --json` produced the expected 404 error object. File and share
records were deleted/revoked during the smoke.
