## Deliberate deviations from the spec for the alpha

- Unsigned binaries, no installers, no cosign/SBOM yet.
- Windows credential DACL verification is a placeholder (relies on `%APPDATA%`
  default ACLs). Tracked in TODO as the first Windows follow-up.
- Stdin/file inputs are buffered in memory (bounded 50 MiB) rather than spooled
  to a protected temp file. Same content-length guarantee, no temp data risk.
- Only Linux amd64 was runtime-tested today; the other five targets are
  cross-builds.

## Public-alpha preparation: audit, installers, self-update

Pre-publication audit: no secrets anywhere; the copied application spec
(`docs/spec.md`) was the only infrastructure disclosure and was removed from
the tree. Because it exists in every earlier commit and the repository will be
public, the owner runs a history purge (filter-branch, force-push, tag
re-point) from a script prepared in the session scratchpad; auto mode refuses
history rewrites. The owner has a zip backup of main.

Shipped `scripts/install.sh` (Linux/macOS) and taught both installers to
resolve "latest" from the release `manifest.json`, so no GitHub API or token
is needed. CI now tests both installers on ubuntu, macos and windows runners
against a local release server (latest, pinned, checksum mismatch fails
closed, uninstall). One CI flake traced to the file server not being ready;
replaced fixed sleeps with readiness loops.

Added `internal/update` and `agentdrop update [--check] [--to vX] [--json]`:
resolves the target version, downloads the platform archive, verifies SHA-256
against `checksums.txt`, extracts the executable, and replaces the running
binary atomically (rename aside on Windows, cleaned up on the next run).
Refuses package-manager paths and plain HTTP unless the caller chose a custom
release root. Unit tests cover version ordering, replacement, checksum
failure leaving the target intact, missing assets, managed paths and zip
extraction; a live run replaced a running dev binary with a fake release on
this host. README and compat.md document install, update, uninstall, and the
Windows caveats.

Application repository: rewrote the site CLI guide (native installers, manual
install with checksums, update/uninstall, supported platforms, Windows
troubleshooting, issue link), updated README, `docs/site-docs.md`, and the
agent skill's install pointer. Deployment waits for the repository to be
public.
