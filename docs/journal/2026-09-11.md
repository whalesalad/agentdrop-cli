## Deliberate deviations from the spec for the alpha

- Unsigned binaries, no installers, no cosign/SBOM yet.
- Windows credential DACL verification is a placeholder (relies on `%APPDATA%`
  default ACLs). Tracked in TODO as the first Windows follow-up.
- Stdin/file inputs are buffered in memory (bounded 50 MiB) rather than spooled
  to a protected temp file. Same content-length guarantee, no temp data risk.
- Only Linux amd64 was runtime-tested today; the other five targets are
  cross-builds.

## Live smoke evidence (linux-amd64 archive binary, production)

Existing Node profile file loaded without login. `whoami --json` returned
account/entitlements/quota. Disposable 200,000-byte random file: `put` →

follow-up `info --json` produced the expected 404 error object. File and share
records were deleted/revoked during the smoke.

## Follow-up: CI on Windows and the Windows test strategy

The only failed GitHub run was the first CI push's `windows` job (two Unix-only
assertions in `store_test.go`); the fix landed in commit `test: make credential
store tests portable to Windows` and the rerun passed. That job had only run
`internal/api` and `internal/auth`, so it was weak evidence. Changes:

- `exec` tests now use the test binary as a helper child process (TestMain
  hook) instead of `sh -c`, so they run unchanged on Windows.
- Symlink and permission assertions are skipped where the platform lacks them;
  the Windows DACL gap stays tracked in TODO.
- The `windows` CI job runs `go test ./...`, builds `agentdrop.exe`, and smokes
  it from PowerShell and cmd.exe (`--version --json` target check, help text,
  token validation message, `logout` with a redirected `%APPDATA%`).
- Wrote `docs/windows-testing.md`: host inventory (KVM ready, libvirt/swtpm not
  installed, no Windows ISO on disk), a Windows 11 VM recipe with UEFI + Secure
  Boot + emulated TPM, OOBE local-account snag, snapshot workflow, and a
  14-step manual checklist covering install, login/storage, file operations,
  locked-destination replacement, PowerShell pipe encoding, VS Code integrated
  terminal, the agent skill, `exec`, and WSL.

Decision: test on Windows 11 only; Windows 10 shares every Windows code path
and adds no coverage. Unactivated Windows is fine for this.
